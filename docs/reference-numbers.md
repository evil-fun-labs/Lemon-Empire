# Published idle-game numbers (sourced 2026-11-10; for the economy model, not yet applied)
- Cost growth per unit owned: Cookie Clicker 1.15 (doubles about every 5, x1000 every 50); AdVenture Capitalist lemonade stand 1.07, base cost 4, base output 1.67/s, stacking x2 output at 25 and 50 owned. (Cookie Clicker wiki Buildings; Pecorella, Math of Idle Games Part I)
- Tier base cost rises about 10-16x per tier early/mid, base output only about 5-8x per tier, so payback per tier lengthens. (Cookie Clicker wiki, author's arithmetic)
- Prestige: Cookie Clicker levels = cube root of (all-time cookies / 1 trillion), +1% output per level, additive. AdCap: +2% output per angel, multiplier 1 + 0.02 x angels. (wiki pages)
- Not found: benchmarks for time to first prestige or how much faster the next run should be. The 70% and x1.5 figures stay design proposals, to be tested.
